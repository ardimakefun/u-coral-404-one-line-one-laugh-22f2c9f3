# One Line, One Laugh

One original single-line joke (98 characters) for make.fun's
"One Line, One Laugh" bounty, $2 in total ($1 / $1) to the two
funniest lines. A judge model compares the lines head to head, so
the writing is the whole contest.

> My password is so strong even I can't log in — which, honestly, is the most secure I've ever felt.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the line to `/output/entry.txt`.
